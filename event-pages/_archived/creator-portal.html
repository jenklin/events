Deployment Instructions

Pre-Deployment Checklist

1 Generate Event Page

Create your event page from the configuration:

npm run generate:event path/to/your-config.json

This creates a fully functional event page in event-pages/output/

2 Deploy to Cloudflare Pages

Deploy the event page to production:

# Install Wrangler CLI (if not installed)
npm install -g wrangler

# Deploy to Cloudflare Pages
wrangler pages publish event-pages/output --project-name=your-event-name

3 Configure Custom Domain

In the Cloudflare Dashboard:

  1. Navigate to Workers & Pages → Your project
  2. Go to Settings → Custom domains
  3. Click Set up a custom domain
  4. Enter your domain (e.g., your-event.cloudpeers.com)
  5. Wait for DNS propagation (usually 1-5 minutes)

4 Test Live Site

Once deployed, verify these features:

  • Visit your event URL
  • Test registration form with a real email
  • Verify QR code works on mobile
  • Test potluck sign-ups (if enabled)
  • Test music requests (if enabled)
  • Check mobile responsiveness
  • Confirm all links work correctly
